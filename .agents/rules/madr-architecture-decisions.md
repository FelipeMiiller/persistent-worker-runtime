# MADR Architecture Decisions

Any structural modification, concurrency semantic change, or new execution paradigm must be documented in an **Architecture Decision Record (ADR)**.

## Rules

1. Format: Strictly follow **MADR** (Markdown Architectural Decision Records).
2. Location: Place all records in `docs/adr/NNNN-kebab-case-title.md`.
3. Indexing: Every new record must be referenced in `docs/adr/README.md`.
4. Language: All ADRs must be written in clear, professional English.
